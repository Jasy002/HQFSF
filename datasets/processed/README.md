# Processed Dataset

This directory contains all datasets generated by the HQFSF preprocessing pipeline.

## Purpose

The files in this folder are created automatically after the raw dataset has been:

- Loaded
- Validated
- Cleaned
- Preprocessed
- Split into training and testing sets
- Exported into multiple formats

Do not edit these files manually.

---

## Files

### processed_dataset.csv

The complete processed dataset after preprocessing.

Contents:
- ID column removed
- Missing values handled
- Duplicate records removed
- Categorical labels encoded
- Numerical features standardized
- Target column retained

---

### train.csv

Training dataset generated using the train-test split.

Default split:
- 80% Training Data

---

### test.csv

Testing dataset generated using the train-test split.

Default split:
- 20% Testing Data

---

### dataset.xlsx

Processed dataset exported in Microsoft Excel format.

---

### dataset.json

Processed dataset exported in JSON format.

---

### dataset.parquet

Processed dataset exported in Apache Parquet format for efficient storage and high-performance data processing.

---

## Generation

These files are generated automatically by:

- `datasets/preprocess.py`
- `datasets/splitter.py`
- `datasets/exporter.py`
