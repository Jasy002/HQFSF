# Datasets

This directory contains all datasets and related resources used in the **Hybrid Quantum Feature Selection Framework (HQFSF)** project.

The dataset pipeline supports loading, validation, preprocessing, metadata generation, train-test splitting, and exporting the processed data into multiple formats for classical and quantum machine learning experiments.

---

## Folder Description

### raw/

Stores the original datasets exactly as downloaded.

Contents:
- Original dataset files
- No preprocessing or modifications

Example:

```text
raw/
├── Breast_Cancer_Wisconsin.data
├── Breast_Cancer_Wisconsin.names
└── README.md
```

---

### processed/

Contains datasets generated by the preprocessing pipeline.

Generated files:

- processed_dataset.csv
- train.csv
- test.csv
- dataset.xlsx
- dataset.json
- dataset.parquet

---

### metadata/

Stores dataset documentation and descriptive information.

Example files:

- dataset_info.json
- feature_names.txt
- target_info.txt
- statistics.json

---

### external/

Optional directory for external datasets, compressed archives, or backup files.

---

## Dataset Workflow

The complete dataset processing pipeline follows these steps:

1. Download or copy the original dataset into `raw/`.
2. Load the dataset using `loader.py`.
3. Validate the dataset using `validator.py`.
4. Remove unnecessary columns (e.g., ID).
5. Handle duplicate records.
6. Handle missing values.
7. Encode categorical labels.
8. Standardize numerical features.
9. Split the dataset into training and testing sets.
10. Export the processed dataset into multiple formats.
11. Generate and update dataset metadata.

---

## Notes

- Original datasets should never be modified.
- All preprocessing is performed automatically by the HQFSF preprocessing pipeline.
- Generated datasets can be recreated at any time by rerunning the preprocessing module.
- Metadata files should remain synchronized with the processed dataset.
