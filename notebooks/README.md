# HQFSF Notebooks

This folder contains interactive Jupyter notebooks demonstrating the complete workflow of the Hybrid Quantum Feature Selection Framework (HQFSF).

## Notebook Overview

### 01_data_exploration.ipynb
- Load dataset
- Inspect data
- Missing values
- Correlation analysis
- Data visualization

### 02_data_preprocessing.ipynb
- Data cleaning
- Encoding
- Feature scaling
- Train-test split

### 03_quantum_feature_selection.ipynb
- Quantum encoding
- Variational Quantum Circuit
- Expectation value computation
- Feature ranking
- Feature selection

### 04_model_training.ipynb
- Logistic Regression
- Support Vector Machine
- Random Forest

### 05_evaluation.ipynb
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

### 06_benchmark.ipynb
- Compare all classifiers
- Runtime comparison
- Feature reduction

### 07_visualization.ipynb
- Feature importance
- Confusion matrix
- ROC curve
- Runtime plots

### 08_complete_hqfsf_pipeline.ipynb
Complete end-to-end demonstration of the HQFSF framework.
